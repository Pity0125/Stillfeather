Your own sidebar sections, middle-click for new tabs, and a path bar that runs programs:
• Right-click empty space in the sidebar to add sections alongside Favorites and Drives, drag folders in to pin them, and drag sections to reorder them
• Middle-click a folder to open it in a new tab, as many as you like in a row
• The path bar runs programs and commands like Win+R; type cmd to open a command prompt in the current folder
• Press ↓ in the search box for your last 10 searches, filters included
• Set a shortcut by clicking a command and pressing the keys you want
• Box selection no longer lags, even with a very large box
