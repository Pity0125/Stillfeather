More room for your files, larger text, and a reorganized Settings:
• The file list gets more room: the current folder is the last part of the path bar, filter chips and action buttons share one row, and the bottom is a single status line
• New View › Text size (100%–150%) enlarges file names, columns, the sidebar, tabs and the status line
• Settings now has categories on the left and their options on the right, with a live preview for text size
• Each part of the path has an arrow that lists the subfolders at that level
• The Sort menu now includes what the A–Z / Newest / Size chips used to do
• Shortcuts, programs and icon files show their own icons instead of one generic white shortcut icon
